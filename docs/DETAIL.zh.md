# 任务清单

一个会话视图（View），入口在会话标签行，与「轨迹」「统计」等视图并列。

## 界面

- 顶部是标题、说明和所属项目；中间是紧凑的事项列表（行间细分隔线，不做卡片）；**输入区与「自动执行」开关吸底固定在下方**。
- 视觉沿用 DSH 的控件规范：主题圆角与颜色变量、品牌色主按钮、次要操作（编辑/删除）默认弱化、悬停才显现。
- 列表顺序：**已完成的事项在上，新添加的事项在下**；失败、执行中的事项排在待执行之前。

## 功能

- 在视图里记录事项，列表保存在本浏览器中，刷新页面后仍在。
- **按项目隔离**：每个工作区（Workspace）各有一份清单，切换到其他项目的会话只显示该项目的事项。
- **每条事项可选范围**（优先级下拉框右侧）：
  - `这个对话`：只在本会话的清单里出现，发送时也只在本会话执行。
  - `全部`：在本项目的所有会话里都出现，便于跨对话管理同一批事项。
- 每条事项可设置优先级（高 / 中 / 低）；已添加的事项也能直接点优先级标签改成其他档位。
- **直接点任务标题就能修改内容**（光标变成文本光标）：Enter 保存，Shift+Enter 换行，Esc 取消；**点任务以外的任何地方也会自动保存并退出编辑**；删除是悬停行尾才出现的轻量图标。
- 点「发送」把该事项作为一条排队消息发给当前会话，由 AI 执行。
- 「自动执行」开关**按对话独立**：只影响当前会话；开启后会话空闲时自动发送本对话可见、优先级最高的待办事项，逐条执行直到清空，切换到「对话」等其他视图也会继续。
- 每条事项实时显示进度：待发送、执行中、已完成、发送失败（附错误信息），并标注该项属于「本对话」还是「全部」。

## 说明

- 事项数据保存在浏览器本地存储中，按工作区分组，不跨设备或浏览器同步。
- 其他对话的「这个对话」事项不会显示，只在底部提示「N 项其他对话的事项」。
- 优先级、范围的选择按对话记住；「自动执行」也是每个对话各自的开关，默认关闭。
